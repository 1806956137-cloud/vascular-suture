# 基于 XPBD 的血管端对端缝合模拟

这是一个 Unity 血管缝合模拟项目。当前演示将双层血管沿环周切开并分离，缝合近端与远端两个断端，因此属于**端对端吻合**，不是侧对侧吻合。

## 已实现

- **手动缝合**：通过场景中的针具控制器操控缝合针，完成进针、穿过血管壁、出针和拉线收拢的过程。
- **六针自动缝合**：根据两侧环周切口边界生成六组配对针位；先完成相隔约 120° 的三针定位缝合，再在三个区间各补一针。每组依次穿过两侧血管壁并拉线。
- **双层血管变形**：外壁与内壁共同参与模拟，针具接触、穿刺孔位和缝线牵拉会影响局部形变。

## XPBD 实现

血管壁网格顶点作为粒子。每步先由速度、重力和阻尼预测位置，再迭代求解约束，最后用修正后的位置更新速度和网格。面内距离、相邻三角面的弯曲角以及内外壁厚度连接采用 XPBD：为约束保存拉格朗日乘子 `λ`，用柔度 `compliance` 控制软硬，按 `α = compliance / Δt²` 计算每轮的位置修正。求解任务由 Unity Job System 调度。

主要约束包括：

- **距离与弯曲**：维持网格边长和相邻面片的弯曲形态。
- **跨层厚度与分层**：连接内外壁，并限制外壁进入内壁。
- **固定与碰撞**：固定血管端部，处理针具及其他碰撞体与血管壁的接触。
- **穿刺与缝线**：维护针尖局部作用、穿刺通道和孔位；配对孔位由拉线约束逐步收拢，并处理缝合区域的局部接触。

## 数据结构

粒子的位置、预测位置、速度和质量保存在按顶点索引访问的 `NativeList` 中；网格三角形索引和边拓扑用于生成约束。距离、弯曲、固定、碰撞、跨层连接及缝线分别使用独立的约束结构；XPBD 乘子保存在与对应约束一一匹配的数组中。内外壁合并到同一求解器，通过对应的顶点身份建立厚度连接。

## 运行

使用 **Unity 2022.3.62f3c1** 打开项目，载入 `Assets/TestScenes/Vessel_PBDTest/SingLayer.unity` 并进入 Play 模式。场景会按参数生成环周切口；可使用 `NeedleSceneControlRig` 手动操针，或在 `AutoSutureSystem` 组件菜单中选择 **Start Auto Suture** 运行自动缝合。
