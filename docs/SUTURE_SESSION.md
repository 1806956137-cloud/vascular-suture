# 主页与六针双模式

2026-10-30 修订。入口场景：`Assets/TestScenes/Vessel_PBDTest/SingLayer.unity`，Unity 2022.3.62f3c1。

## 开始使用

打开主场景后点击 Play，先进入深色蓝灰＋青绿的主页。主页保持仿真暂停，等待选择手动或自动。

手动模式按六针顺序推进。每一针近端、远端在双层血管上的全部孔位统一显示为青绿表面圈，颜色、尺寸和亮度一致，不区分进针或出针。目标沿用自动缝合的材料锚点，每帧投影到当前渲染网格；内壁和背面的标记遵循组织遮挡，转动视角后可见。操作画面仅显示针次编号，右栏提示“近端、远端各完成一次穿刺后，拉线一次，再继续下一针。”显示简化不改变原有穿刺记录和推进校验。

| 操作 | 输入 |
|---|---|
| 针具锁定 | 手动模式默认选中并锁定；同一按钮可取消选中或重新锁定 |
| 聚焦针具 | 独立的“聚焦针具”按钮，仅调整视角 |
| 移动针具 | 默认移动工具；选择“移动”或按 1，锁定后在操作区左键拖动；Q/E 调整远近 |
| 沿针轴推进/回退 | 选择“推进”或按 2，沿针尖在屏幕上的朝向拖动推进，反向拖动回退 |
| 操针速度 | 右侧滑条 0.2×–3.0×，默认 1.0×，作用于移动、推进、转向和滚转 |
| 调整朝向 | 选择“转向”或按 3，左键拖动 |
| 绕针轴滚转 | 选择“滚转”或按 4，左键左右拖动 |
| 精细操作 | 按住 Shift，或点击精细模式开关 |
| 相机观察 | 右键旋转、中键平移、滚轮缩放 |
| 聚焦/整体/恢复跟随 | 视图上方按钮，或 F/G/R |
| 暂停/继续 | 右栏按钮，或空格；暂停时仍可观察 |
| 操作说明/暂停菜单 | 操作帮助按钮，或 Esc；再次 Esc 关闭菜单 |
| 保存仿真视图 | 截图按钮或 F12；JPG 保存在工程 `PatentScreenshots`，沿用原有不含 UI 的相机截图 |

手动进度仅依据当前针具的独立完整穿刺事件：双层穿透并退出针体后计一次，同一事件不重复计数。不再匹配参考孔位、预设方向或预设侧别；已结束但未完成的记录不阻挡后续有效事件。每两次穿刺后开放拉线，实际收拢达到原有推进条件后进入下一针。操作者自行完成两侧穿刺，界面只显示穿刺次数，不把事件计数表述为侧别验收。孔位圈仅供参考，不是评分目标。

自动模式进入后先预览，点击“开始六针缝合”才执行原有算法。执行时锁定手动操针和针位编辑；“调整针位”仅在预览阶段可用。完成后可观察、截图或重置，流程完成不等于贴合质量验收。

返回主页和重置会重新加载完整场景，清空本轮组织变形、孔道与针线状态。实际操针或自动执行后，返回主页会提示放弃本轮；只点击界面开关不会被当作操针。

锁定保持的是针具的选中状态。背景点击和工具切换不会取消锁定；取消后背景拖动不再操针，仍可直接点击针身重新选中。速度设置作用于四种工具，新一轮恢复 1.0×。调整速度、暂停或失焦时清除未处理的拖动，避免积累鼠标位移。界面点击判定使用当前鼠标位置，防止刚点完工具按钮后首次拖动被当作仍在界面上。

## 工程接入

- `SutureSessionController`：显式绑定原自动控制器、双层仿真驱动和针具，管理两种模式、暂停与重载。
- `NeedleDesktopInput`：仅手动模式开放键鼠输入，处理拖动、精细操作与失焦取消。
- `ManualSutureGuide`：独立的顺序与证据校验，不修改物理解算。
- `SutureSurfaceGuidance`：将每个孔位圈的顶点贴合到当前双层血管表面，保留真实深度遮挡。
- `SutureSessionView`：运行时创建 uGUI、目标提示与帮助。主场景通过新组件接入，不需手工搭 Canvas。
- 原自动控制器增加会话接入、显示、针具聚焦和输入门控，穿刺、避障、拉线算法保持现有实现。
- `ClothSimulator` 构造时即计算真实几何法线，解决主页暂停在首个物理步之前时，渲染组件读取未初始化法线的问题。
- 主页两个入口默认同色，只在点击后短暂高亮；血管示意以遮罩内的端部染色代替悬空圆圈。
- Build Settings 已加入主场景，独立程序使用同一场景重载入口；尚未执行独立程序构建验证。

## 针具工具表征

选中针具后显示半透明图形，随针位及工具变化；取消选中、离开手动模式或打开菜单时隐藏。移动为视平面十字双向箭头，推进为针尖前方的轴向箭头，转向为两组弧形箭头，滚转为绕针轴的环形箭头，并附侧向环形提示以便在环面侧视时辨认。图形不参与碰撞、拾取或针具驱动。
